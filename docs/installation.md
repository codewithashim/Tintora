# Tintora Installation & Quickstart Guide

This guide walks you through installing, setting up, and customizing the **Tintora** WordPress theme for window tinting and glass film businesses.

---

## 1. System Requirements

- **WordPress Version**: 6.0 or higher
- **PHP Version**: 8.1 or higher
- **Web Server**: Apache or Nginx
- **MySQL Version**: 5.7+ or MariaDB 10.3+

---

## 2. Installation Steps

### Option A: WordPress Admin Dashboard
1. Log in to your WordPress Administrator Dashboard.
2. Navigate to **Appearance > Themes**.
3. Click the **Add New** button at the top.
4. Click **Upload Theme** and select `tintora.zip`.
5. Click **Install Now**, then click **Activate**.

### Option B: Manual FTP / Server Installation
1. Extract the `tintora` theme folder from the ZIP archive.
2. Connect to your web server using FTP or SFTP.
3. Upload the `tintora` directory to `/wp-content/themes/`.
4. Log into WordPress Admin, navigate to **Appearance > Themes**, and click **Activate** on Tintora.

---

## 3. Initial Homepage Setup

1. Create a new page under **Pages > Add New** named "Home".
2. In the right panel under **Page Attributes > Template**, select **Homepage Builder** (or leave as default).
3. Publish the page.
4. Go to **Settings > Reading**.
5. Under **Your homepage displays**, choose **A static page**.
6. Select your "Home" page as the Homepage.
7. Click **Save Changes**.

---

## 4. Recommended Plugins

Tintora operates 100% standalone without requiring page builders, but integrates with these plugins:

- **Contact Form 7** or **WPForms** for custom form fields and instant quote inquiries.
- **WooCommerce** if you sell window film products, cleaning kits, or ceramic maintenance packages.
- **Yoast SEO** or **Rank Math** for site SEO optimization.
