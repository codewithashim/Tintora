# Tintora Customizer & Configuration Guide

All visual branding, colors, phone numbers, and hero copy in **Tintora** can be adjusted live using the standard WordPress Customizer, or designed visually using Elementor Page Builder.

---

## Accessing the Customizer

1. Log into WordPress Admin.
2. Go to **Appearance > Customize**.
3. Open the **Tintora Theme Settings** panel.

---

## Customizer Panels & Controls

### 1. Business & Contact Info
- **Phone Number**: Displays in the header, mobile drawer, and sticky bottom action bar.
- **Email Address**: Used in footer widgets and contact sections.
- **Business Address**: Displayed in contact details.
- **Business Hours**: Displayed in contact details.
- **Enable Mobile Sticky Action Bar**: Toggles the bottom Call, WhatsApp, and Quote bar on mobile screens.

### 2. Header Settings
- **Enable Sticky Header**: Keeps the navigation bar fixed to the top during scrolling.
- **Transparent Header on Homepage Hero**: Blends the header over the dark hero background.
- **Header Button Text & Link**: Customizes the top right quote CTA button.

### 3. Theme Colors (CSS Variables)
- **Primary Dark Color**: Default `#111111`. Used for header, footer, dark hero, and dark CTA sections.
- **Accent / Gold Color**: Default `#D09A40`. Used for CTA highlights, badges, star ratings, and button gradients.
- **Body Background Color**: Default `#F7F7F5`.
- **Main Text Color**: Default `#222222`.
- **Muted Text Color**: Default `#6B7280`.

---

## Elementor Page Builder Integration

When the **Elementor** plugin is installed and active, Tintora unlocks native drag-and-drop custom widgets in the Elementor panel under the **Tintora Theme Widgets** category:

1. **Tintora Hero Section**: Drag & drop hero banner with live stat counters.
2. **Tintora Before/After Slider**: Draggable image comparison widget.
3. **Tintora Service Card**: Modular service box with icon selection.
4. **Tintora Pricing Card**: Tier package box with featured badge controls.
5. **Tintora FAQ Accordion**: ARIA accessible accordion repeater widget.
