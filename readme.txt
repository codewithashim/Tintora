Tintora is a modern, fast, SEO-friendly, and conversion-focused WordPress theme designed for window tinting and window film businesses.

== Description ==

Tintora is tailored specifically for window tinting, automotive film, residential glass protection, commercial solar control, security film, UV rejection, and automotive detailing businesses.

Built with a modern SCSS architecture, vanilla JavaScript, WCAG 2.2 AA accessibility principles, and WooCommerce support, Tintora delivers high-performance conversions out of the box without requiring heavy third-party page builders.

= Features =

* High-converting Hero section with customizable live statistics counters.
* Interactive Draggable Before / After Image Comparison Component (Vanilla JS).
* Filterable Project Gallery & Zero-Dependency Lightbox Modal.
* Accessible FAQ Accordion (WCAG 2.2 AA compliant).
* Full SCSS styling pipeline with custom design tokens.
* Integrated WordPress Customizer API with live Selective Refresh.
* WooCommerce shop, product grid, cart & checkout compatibility.
* Form plugin styling hooks for Contact Form 7, WPForms, and Gravity Forms.
* Mobile Sticky Action Bar (Call, WhatsApp, Get Quote).
* Translation-ready (`tintora` textdomain) & RTL ready.

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes.
2. Click "Add New" and then "Upload Theme".
3. Upload the `tintora.zip` file and click "Install Now".
4. Click "Activate" to enable the theme on your site.
5. Go to Appearance > Customize to configure branding, hero copy, colors, and phone numbers.

== SCSS Compilation ==

Developers can compile SCSS source files in `assets/scss/`:

```bash
npm run build:scss
# or during active development:
npm run watch:scss
```
